# BookNook – A Small Online Library

BookNook is a small online library where users can explore books, add their own books, borrow available books, and manage their reading activity.

## Live Website
Coming soon.

## Technologies Used
- Next.js
- React
- Tailwind CSS
- Express.js
- MongoDB
- Better Auth
- ImgBB

## Key Features
1. User registration and login with email/password.
2. Google authentication.
3. Browse and search books by title or author.
4. Filter books by category.
5. Add books with image uploads.
6. View detailed information about each book.
7. Borrow available books.
8. Return borrowed books.
9. Manage, edit, and delete your own books.
10. View your profile and update your information.
11. Responsive design for desktop and mobile devices.

## Installation

Clone the client repository:

```bash
git clone https://github.com/fuadcodesDev/booknook-client.git
cd booknook-client
npm install
npm run dev
```

Create a `.env.local` file and configure the required environment variables.
